## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

We plan to make a simple game in Python using Pygame. The player uses the left and right arrow keys to move a cat at the bottom of the screen. Fish will fall from random position at the top of the screen. Each fish the cat catches gives one point. If the cat misses a fish, the game is over and the final score will be shown. We also want to make our own background music for the game. To play the game, you just need to run the Python file with Pygame installed.
